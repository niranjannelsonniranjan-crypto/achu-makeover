Project Overview

Achu Bridal Studio is a luxury bridal makeup studio in Trichy, Tamil Nadu, specializing in traditional and contemporary bridal looks. This project includes a responsive website with booking functionality, admin panel, and service management.

Tech Stack

  • Frontend: HTML5, CSS3, JavaScript (Vanilla)
  • Backend: Node.js, Express.js
  • Database: MongoDB (Local)
  • Hosting: Vercel (Frontend), Local (Backend)

How to Run the Project

Step 1: Start MongoDB (Local)

  1. Open the project folder: C:\New folder\Achu bridal
  2. Double-click start-app.cmd
  3. The script will automatically start MongoDB and Express server
  4. Keep the command window open while using the website

Step 2: Open the Website

  1. Open index.html in your web browser
  2. The website will load with all features

Step 3: Access Admin Panel

  1. Open admin.html in your web browser
  2. Login with credentials:
    • Email: admin@achubridal.com
    • Password: Admin@12345

Step 4: Stop the Server

  • Go to the command window where start-app.cmd is running
  • Press Ctrl + C
  • MongoDB and server will stop

Booking System

Booking Process

  1. User fills out booking form
  2. Selects service (Bridal, Party, or HD Makeup)
  3. Chooses date and time
  4. Submits form
  5. Backend validates and saves to MongoDB
  6. Admin can manage bookings

Booking Fields

  • Name: Required, max 80 characters
  • Phone: Required, validated format
  • Email: Required, validated email
  • Service: Required (Bridal, Party, HD Makeup)
  • Date: Required, must be future date
  • Time: Required
  • Message: Optional, max 500 characters
  • Status: Auto-set to 'pending'

Troubleshooting

MongoDB Won't Start

  • Check if port 27017 is already in use
  • Delete .tools/mongodb-data folder to reset database
  • Check .tools/mongodb-logs for error messages

Server Won't Start

  • Check if port 5000 is already in use
  • Run cd server && npm install
  • Check server logs for errors
  • Verify MongoDB is running first

Booking Form Not Working

  • Ensure server is running (port 5000)
  • Check browser console for errors
  • Verify MongoDB is connected
